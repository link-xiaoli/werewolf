## 1. 启动项目

环境要求:Node.js 18+(建议 20+)。

```bash
npm install
npm run dev
```

浏览器打开终端提示的地址(默认 <http://localhost:5173>,端口被占用会自动顺延)。

> 不配置任何 Key 也能开局:AI 会退化为随机决策的"笨 AI"、没有声音,适合先看 3D 场景和流程。配置完 Key 后 AI 才"活"过来。

## 2. 注册 DeepSeek

DeepSeek 负责每个 AI 角色的"大脑":发言、投票、夜晚行动、插话都由它生成。

1. 打开 <https://platform.deepseek.com>,注册并登录(支持手机号)
2. 左侧菜单「**API Keys**」→「**创建 API Key**」,复制 `sk-` 开头的 Key
3. 左侧菜单「**充值**」,充 10 元即可(官方最低额度)。**一局 6 人狼人杀约消耗几万 token,成本约几分钱**
4. 回到游戏设置页,粘贴到「**DeepSeek Key**」,点「**测试 DeepSeek**」,显示连接成功即完成

注意事项:

- 默认模型 `deepseek-flash` 是 2026 年现行模型名;历史教程里的 `deepseek-chat` 已于 2026 年 7 月停用,不要填
- Key 只保存在你自己的浏览器里(localStorage),不会上传到任何服务器
- 浏览器直连 DeepSeek 目前可行(2026-09 实测);若将来官方收紧跨域,把设置页「Base URL」改成 `/llm` 可走本地开发代理兜底

## 3. 注册讯飞

讯飞负责语音朗读:法官播报、每个角色的发言都由它合成。

1. 打开 <https://www.xfyun.cn>,手机号注册
2. 进入控制台 → 找到「**语音合成(流式版)**」→「**创建应用**」(免费开通即可)
3. 在应用详情页找到三样东西,依次复制到设置页:
   - **APPID**(应用编号)
   - **APIKey**(接口密钥)
   - **APISecret**(接口秘钥)
4. 点「**测试讯飞发音**」,应该听到一句"你好,这是AI狼人杀的语音测试"

注意事项:

- 免费额度:每天 500 次调用,个人玩绰绰有余
- **讯飞会校验请求时间**,如果你的电脑时钟偏差超过 5 分钟会被拒绝(报 401 或"HMAC signature 校验失败"),先校正系统时间
- 每个座位自动分配一个不同音色(共 12 个轮询);法官单独一个音色

## 4. 设置页说明

| 设置项 | 说明 |
| --- | --- |
| 你的昵称 / 座位 | 你在 3D 圆桌上的名字和位置 |
| 人数预设 | 6 人新手局 / 9 人标准局 / 12 人完整局,一键填入角色配比 |
| 自定义角色数量 | 狼人/预言家/女巫/猎人/守卫/村民各配几个,自由组合(5~12 人) |
| 观战模式 | 你不参与,全 AI 自动玩,适合演示和挂机测试 |
| 快速模式 | 不朗读语音,纯文字快节奏(也省讯飞额度) |
| 死者遗言 | 死亡/被放逐者在黄昏留下遗言(默认开) |
| AI 自由插话 | 别人发言时 AI 举手打断(默认关,打开更有真人感) |
| 重试 · 并发 | 左:每个 AI 决策最多尝试次数(默认 3);右:同时进行的大模型调用数上限(默认 4)。网络不稳定可调 6 次 / 2 路;追求速度可 2 次 / 8 路 |

## 5. 玩法详解

### 5.1 角色

| 角色 | 阵营 | 能力 |
| --- | --- | --- |
| 村民 | 好人 | 无能力,白天投票 |
| 预言家 | 好人 | 每晚查验一人是好人还是狼人 |
| 女巫 | 好人 | 解药、毒药各一瓶,同晚限用一瓶,可自救(可配) |
| 猎人 | 好人 | 被狼杀/被放逐可开枪带走一人(被毒死不能开) |
| 守卫 | 好人 | 每晚守护一人,不能连续两晚守同一人 |
| 狼人 | 狼人 | 互相知道队友;每晚各自提名,多数票定刀口 |

### 5.2 一局的流程

```
发牌(第 1 夜:查看身份)
  ↕ 夜晚:守卫守人 → 狼人刀人 → 预言家查验 → 女巫救/毒 → 结算
  ↕ 天亮:法官宣布死讯(夜里被狼杀的猎人此时可以开枪)
  ↕ 白天:按顺序发言(可插话)→ 投票放逐(平票无人出局)→ 猎人开枪
  ↕ 黄昏:死者遗言
  → 循环直到分出胜负
```

- 胜负:狼人全灭 = 好人胜;存活狼数 ≥ 好人数 = 狼胜
- 放逐者亮身份,夜间死者不亮;结算页亮明全部身份

### 5.3 你的操作

- **夜晚**:如果你是能力者,画面中央会弹出行动面板(点选目标 / 用药 / 开枪);平民则显示"请闭眼等待"
- **白天**:轮到你时底部出现输入框,打字发言(勾选"朗读我的发言"可让电脑读出你的话);也可以点「跳过」
- **投票**:弹窗点选放逐目标,或「弃权」
- **随时**:右上角「跳过语音」掐断当前朗读;右下角日志卷轴是全场文字记录;顶栏显示阶段与天数

### 5.4 AI 角色的性格

每个座位的 AI 有固定人设(与昵称绑定):阿强冲动带节奏、老王倚老卖老、大壮三句话憋不出一个屁、晓芸阴阳怪气……他们的发言风格整局保持一致,但不会套模板。

> 想调整人设:编辑 `src/game/agents/personas.ts`;想调整发言风格与规则:编辑 `src/game/agents/prompts/`(改提示词不用动代码)。

## 6. 调试技巧

- **控制台自动对局**:浏览器按 F12 打开控制台,执行 `__ww.debug(20)` 连续自动跑 20 局全 AI 对局,输出每局胜者/轮数/用时(验收用)
- **AI 降级记录**:日志卷轴里 `[某人 发言降级:原因]` 是 AI 失败后的保底行为;重试过程见控制台 `[retry]` 日志
- **统计用量**:设置页显示累计 DeepSeek 调用次数
- **跑测试**:`npm test`(25 个用例:规则单测、20 局不死锁、重试机制、语音串行保证)

## 7. 部署到网上

本项目是纯静态站点,构建产物在 `dist/` 目录,可托管到任意静态服务(GitHub Pages / Vercel / 腾讯云 COS 等):

```bash
npm run build
```

**必须使用 HTTPS 部署**:浏览器安全上下文(`crypto.subtle`)和讯飞接口都要求 HTTPS,HTTP 下会报错。

- GitHub Pages / Vercel 等平台默认就是 HTTPS,直接部署即可
- Key 存在每个用户的浏览器里,部署公开站点不影响(访客需要自备 Key)
- 若将来公开运营,建议加一层免费 Cloudflare Worker 代理保护流量(见 README FAQ)
